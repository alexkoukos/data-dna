Set up

Quick start

Needs Docker with Compose v2 and free ports 3000, 3100 and 8001.

docker compose up --build
  1. Open the dashboard at http://localhost:3000 (seeded demo data).
  2. Open the demo chat at http://localhost:3100.
  3. TODO: paste something risky and watch the dashboard.

Check text (the gate)

MethodPathWhat it does
POST/v1/inspectInspect a chat request: decision, reasons, findings, masked messages. TODO: request and response schema.
POST/v1/inspect-outputInspect a model answer before it is shown.
POST/v1/inspect-tool-resultInspect a tool result an agent is about to read.
POST/v1/checkExtension check of pasted or typed text.
POST/v1/extension/inspectExtension check using a personal key.
POST/v1/extension/ackRecord that the person chose Send anyway.
GET/v1/extension/meWho the personal key belongs to.
POST/v1/unmaskRestore masked values in an answer for the right person.

Keys and pairing

MethodPathWhat it does
POST/v1/keysCreate a personal key.

GET/v1/demo-usersDemo people for pairing.
GET/v1/policyCurrent policy as the extension reads it.
